# 검정고시-포항 대입 정보 길잡이 데모

검정고시 준비생과 포항 소재 대학 입시를 준비하는 학생에게 필요한 정보를 상황별로 좁혀 보여주는 공익 웹사이트 데모입니다.

## 실행 방법

1. 이 폴더를 내려받거나 압축을 풉니다.
2. `index.html` 파일을 더블클릭해서 브라우저로 엽니다.
3. 체크박스와 선택지를 바꾸면 맞춤 안내 카드가 바로 갱신됩니다.

별도 설치나 서버 실행은 필요하지 않습니다.

## 주요 기능

- 현재 상태별 안내: 중졸 검정고시, 고졸 검정고시, 검정고시 합격 완료
- 목표별 안내: 검정고시 기본 정보, 대입 준비, 제출 서류, 장학금·지원제도
- 포항 소재 대학 우선 안내: 포항공과대학교, 한동대학교, 선린대학교, 포항대학교
- 선택 결과에 따른 `내 상황 요약`, `지금 필요한 정보`, `다음 행동` 자동 변경

## 파일 구조

```text
.
├── index.html
├── styles.css
├── script.js
└── assets/
    └── hero-guidance.png
```

## 수정할 때 보면 되는 파일

- `index.html`: 화면에 보이는 큰 구조와 문구를 수정합니다.
- `styles.css`: 색상, 글자 크기, 여백, 반응형 레이아웃을 수정합니다.
- `script.js`: 체크박스 선택에 따라 바뀌는 맞춤 정보 내용을 수정합니다.
- `assets/hero-guidance.png`: 첫 화면 배너 이미지를 교체할 때 사용합니다.

## 팀원 작업 방식 추천

1. 수정할 내용을 먼저 이슈나 메모로 정리합니다.
2. 한 번에 하나의 주제만 수정합니다.
3. 수정 후 `index.html`을 열어 화면이 깨지지 않는지 확인합니다.
4. 변경한 파일과 수정 이유를 간단히 남깁니다.

## 앞으로 추가하면 좋은 내용

- 실제 검정고시 최신 일정 링크
- 각 대학 입학처 모집요강 링크
- 제출 서류 발급 방법 안내
- 자주 묻는 질문
- 모바일 화면 세부 개선
- 쉬운 말 안내 모드

## 주의

대학 입시 정보와 검정고시 일정은 해마다 바뀔 수 있습니다. 실제 서비스에서는 반드시 교육청 공고와 각 대학 입학처 모집요강을 기준으로 확인해야 합니다.
